# Partner-Logos

Hier liegen die Original-Logos unserer Partner. Die Website nimmt sie von hier und optimiert sie (Kopie nach `src/assets/partners/`).

## Dateinamen

Bitte genau so benennen (klein, Bindestrich), damit sie zur Content Collection `src/content/partners/` passen:

| Partner | Dateiname |
|---|---|
| Torino | `torino.svg` / `torino.png` |
| Basenbox | `basenbox.svg` / `basenbox.png` |
| WU Wien | `wu.svg` / `wu.png` |
| Raiffeisen Software | `raiffeisen-software.svg` / `raiffeisen-software.png` |
| Roiss-Weiss GmbH | `roiss-weiss.svg` / `roiss-weiss.png` |

Gibt es eine helle bzw. weiße Version fürs dunkle Design, zusätzlich mit `-weiss` ablegen (z. B. `wu-weiss.svg`).

## Format

- Am besten **SVG**. Sonst PNG mit transparentem Hintergrund, mind. 400 px breit.
- Kein JPG, keine Screenshots, kein weißer Kasten um das Logo.
- Nur offizielle Logos aus dem Presse- oder Brand-Bereich der Partner, oder direkt von der Kontaktperson.

## Vor Veröffentlichung

- [ ] Jeder Partner hat der Nennung und Logo-Nutzung auf innovaite.at zugestimmt (am besten schriftlich, kurze Mail reicht).
- [ ] Richtige Schreibweise und Link zur Website je Partner bestätigt.
